# Gain and master controls — 2026-10-18

Version 0.25.0-beta adds manual level balancing in the existing Track, Transition and Master views.

## Controls and signal flow

Song gain ranges from −24 to +12 dB before deck processing. Track and Transition A/B edit the same persisted setting. Logical split fragments of the same source share it; independent duplicates remain independent. Gain and output settings support Undo/Redo and project save/load.

Master gain controls music after deck/master effects. The existing independent-volume metronome is then added, followed by the output soft clipper. The M shortcut opens Master. The old inactive auto-gain switch has been removed; there is no automatic normalization.

Soft clipping is enabled by default with a 0 dBFS ceiling, retaining the legacy finite-sample transfer exactly for music without the metronome. Its ceiling can be set from −12 to 0 dBFS or bypassed. Bypassed samples can exceed full scale and clip at the device or in integer/encoded export. This is sample soft clipping, not a true-peak limiter, compressor or attack/release gain envelope. The click now shares its ceiling and output metering; export continues to exclude the click.

## Measurements

Track measures immutable whole-source audio on a background thread: maximum absolute sample and stereo RMS, including silence. A second estimate applies only song gain. These values exclude cuts, stems, transitions, deck processing and master. RMS is not LUFS or perceived loudness; this release makes no loudness-normalization claim. Reloaded sources cannot accept stale measurement results.

Master displays held pre/post sample peaks and maximum instantaneous soft-clip attenuation. These holds aggregate complete 512-frame blocks consumed by the device, rather than worker lookahead. Reset executes in the callback without seeking, flushing audio or resetting stretch state. A partially consumed block is excluded after reset; measurement resumes with the next complete block. While paused, holds clear on the next device callback. No active device means no playback measurements.

Live gain changes apply immediately and do not yet have parameter smoothing. Source measurements are session-local; controls are saved in the mix. Analysis cache remains version 12, and saved beatgrids are unchanged.
