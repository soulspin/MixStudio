# Library workflow — 2026-10-19

Version 0.29 improves existing library browsing and import, without changing analysis version 13, source files or saved-project schemas.

## Find and organize

Actual filenames, including extensions, lead each 40-point row; artist/title are secondary. BPM, key and duration remain compact. Hover anywhere on a row for the complete filename/path, source errors and imported metadata. Details adds folder and genre columns. Filename sorting is case-insensitive with a deterministic full-path tie break. Existing title/artist/key/BPM/genre/folder sorting and multiword path/metadata search remain available.

The sidebar shows indexed roots and nested subfolders, with recursive unique-file counts. Selecting a folder includes descendants using path-component boundaries, so House does not also match House2. Tree construction performs no source filesystem reads. Its structural revision changes when index paths change, independently from per-file BPM/key results. Source management and DJ imports/remapping are collapsed by default. Removing a root from the library does not remove its audio files.

Resize the Library panel vertically and the sidebar horizontally. The file table remains virtualized. Whole-row selection highlighting and dragging include whitespace. Ctrl toggles files; Shift selects a visible range. Anchors are file paths rather than row numbers, so an analysis result or sorting update cannot leave a stale index. Filtered-out selections are pruned; importing multiple files uses visible order.

## Place files

Drag a file row onto a deck or sample lane. The marker and tooltip identify the snapped destination; headers, ruler, overview and tempo lane are not import targets. Escape or release outside valid lanes cancels. The Library's height can be reduced to expose more of the timeline.

A successful drop captures lane and beat before decoding. As corrected in 0.29.1, a main-deck clip's **analysed downbeat** anchors to the marker, so different file lead-ins cannot break beat/bar alignment. Sample clips retain exact visible-start placement. Near timeline zero, deck anchors move forward by complete active-snap units when necessary to retain introductory audio. The resolved half/double-time ratio is explicit so the next frame cannot move the chosen anchor. Subsequent main-deck clips alternate lanes with the current overlap-bars setting (capped at half the previous clip's length); subsequent deck anchors follow active snapping; sample clips remain contiguous on the chosen sample lane. Existing tracks are not moved to make room.

Add last in mix and double-click use the established end-of-mix arrangement. Ratios resolve between appended files, so each following start is computed from the correct predecessor length.

## Loading and undo

Decoding and source cache probes run on a helper thread. Completed results are applied as one batch in one undo step. Failures are reported without preventing valid files in that batch. Entirely failed batches do not create an undo entry. The destination survives loading delays; switching documents or locking editing before completion rejects late results. The final snapshot is taken when the batch is applied, preserving edits made while files were loading.

This release does not alter the audio renderer, stem model, analysis algorithm or musical-key interpretation. It continues to reference original audio rather than bundling or moving it.
