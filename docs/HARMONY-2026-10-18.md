# Harmony guidance — 2026-10-18

Version 0.27 adds an explained harmony panel to the existing Transition view.

## Source-key guidance

Harmonic match shows outgoing A and incoming B's saved whole-track key labels, distinguishing same key, adjacent Camelot numbers in the same mode (including 12↔1), relative major/minor (same number, opposite letters), other relationships and unknown/unrecognized labels. Standard relationships are starting points, not a guarantee. The panel does not invent a percentage or measured confidence.

Key details and mixing tips displays musical key names, the relationship explanation, common matches from A, and listening suggestions. For other relationships it suggests shorter/percussive blends or a bass handover rather than declaring the transition unusable. Recognized source keys are not an analysis of the actual overlap: chords, vocals and tonality can change within a song. EQ does not transpose a song.

Pitch-following-tempo on any logical A/B fragment is called out because source labels may differ from audible keys. Key-lock flags alone do not certify harmony. This version does not add pitch transposition, local-key inference, automatic EQ or arrangement edits. Auto-order's existing scoring is unchanged.

## Listen before editing

Listen together uses the existing processed transition audition with both A and B, the same before/after bars and repeat setting, and existing temporary mute/solo handling. It is unavailable until all logical source fragments are loaded. The normal Monitor A/B controls remain available. Switching/starting audition does not save mixer overrides, change gain or rewrite keys. Existing shared effect-tail semantics apply.

The view supports vertical scrolling; details start collapsed. Saved mix data needs no schema migration, and analysis cache remains version 13. The [separate Beat This! evaluation](BEAT-THIS-EVALUATION-2026-10-18.md) explains why no model replaces the tested grid in this release.
